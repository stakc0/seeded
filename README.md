# seeded

A functional, responsive clone of the public seeded visual language, rebuilt as a seeded project seed-round launchpad shell with working navigation, launch draft form, live board search, copy buttons, responsive layout, and local interaction states.

## Run

```bash
npm run build
npm run dev
```

The reference site was rate-limited by a Vercel Security Checkpoint during capture, so the clone preserves the launchpad-style dark/lime visual direction and functional interaction model without claiming access to proprietary live data or launch APIs.
